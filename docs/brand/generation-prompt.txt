Use case: logo-brand.
Asset type: a single isolated brand symbol for the open-source project Prompt Spider UI; this concept will be recreated as editable SVG and used as favicon.
Primary request: design a memorable, precise, flat vector-style mechanical spider combined with a code symbol. Center one small vertical hot-pink hexagonal/diamond-like abdomen. Inside that pink body use two crisp dark negative-space angle brackets < > as the code cue. Exactly eight articulated mint-green legs, four mirrored on each side, emerge from the body, each composed of only two or three clean angular segments. The top pair reaches diagonally upward, the bottom pair diagonally downward, the middle pairs spread sideways. Legs have substantial consistent strokes, slightly clipped/chamfered corners, precise open spacing; each leg ends in a small solid mint node. The silhouette must read as a spider immediately, and remain clear at 32px.
Composition: one centered symbol with generous transparent margin, square canvas, symbol occupies about 75 percent. Bilateral symmetry, balanced weight, no lettering, no wordmark, no mockup, no tile enclosing the icon.
Palette: pink #F34A87 body, mint #44D79C legs, dark #090A0A negative-space code brackets; transparent background.
Style: restrained technical identity, geometric, sharp, production-ready icon. Strictly flat solid-color shapes. No gradients, no 3D, no glow, no shadow, no texture, no photographic material, no decorative spiderweb, no tiny circuit details. The transparent background is actual alpha, not a checkerboard illustration.
