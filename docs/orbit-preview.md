# Orbital README preview

The orbital preview is rendered from the current application, using the reference demo and `networkView = 'orbit'`. It shows a visual reference run. No model calls were made.

- Runtime canvas: 1080 × 1350, captured by deterministic timeline seeking.
- README GIF: 540 × 675, 10 fps, 209 frames, 20.9 seconds, infinite loop.
- Scope: canvas only; browser chrome, toolbars, drawers, logo, and toasts are excluded.
- Both READMEs use the GIF; `orbit-preview.png` remains the reduced-motion fallback.
- Existing `preview.gif` remains the separate classic-web preview.

Orbital nodes are grouped by route; distances do not represent semantic similarity or causal relationships.
