关于 Prompt Spider UI

使用原生 Canvas 2D 实现逐词扫描、蛛网分流与动态统计。项目根据画面参考重新实现视觉和交互，不声称恢复了原作者源码；运行无需视频文件。

参考演示包含 175 次分流：137 code、27 model、11 you。轨迹与统计依据画面测量；逐词对应、分数与中间运动采用确定性重建，并非原始运行日志。示例提示词中的数字属于文案，不代表运行统计。

自定义模式使用可检查的本地规则，分数仅作演示。分流不会执行代码、调用模型、发送消息或批准操作。“sonnet 5.5”等模型名称仅为视觉标签。REA 外链用于介绍相关调查工具。

快捷键：空格播放/暂停，R 重播，F 沉浸模式，Esc 退出；左右方向键前后跳转。
